# C Calculator

A simple command-line calculator written in C.

## About the Project

This project is a command-line calculator developed in C as a learning project.

The purpose of the project is to practice the fundamentals of the C programming language, including variables, user input, conditional statements, loops, switch statements, and basic error handling.

The calculator allows the user to perform basic arithmetic operations through an interactive menu.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero protection
- Interactive menu
- Input validation for menu choices
- Continuous operation until the user chooses to exit

## Technologies

- **C** – Programming language
- **GCC** – C compiler
- **Git** – Version control
- **GitHub** – Project hosting

## Requirements

Before running the project, make sure you have:

- GCC installed
- Git installed (optional, only needed if you want to clone the repository)
- A terminal such as PowerShell
- A code editor such as Visual Studio Code
